# Family-Organizer-App
Додаток для спрощення спілкування між членами сім’ї. MVP-версія продукту матиме такі функції, як: спільний календар, списки завдань та покупок. Додаток призначений для полегшення щоденного та довгострокового планування сімейних справ.
